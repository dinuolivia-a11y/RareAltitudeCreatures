# Space & Solar System (Starting Point of the App)

The app begins here: realistic views of our Solar System using NASA imagery.

## Our Solar System (first layer)
- Sun
- Mercury
- Venus
- Earth + Moon
- Mars
- Jupiter
- Saturn
- Uranus
- Neptune
- (Pluto and dwarf planets as optional)

## Notes for the app
- Use real NASA images (APOD, planetary photojournal, etc.).
- Later: NASA API key for more data and images.
- After Solar System → other planets in the Milky Way → other galaxies.
- Transition to Earth: user scrolls closer and closer to the planet.

No creatures here, just the journey toward Earth.
