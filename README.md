# Rare Altitude Creatures

Database of rare and little-known creatures organized by geographic zones, biomes and altitude layers.

For an educational app where users explore from space down to the ground (and later into oceans), discovering obscure animals specific to each region.

## Zones
- [Andes](zones/andes.md)
- [Himalayas](zones/himalayas.md)
- [Appalachians](zones/appalachians.md)
- [Amazon](zones/amazon.md)
- [Tian Shan / Central Asia](zones/tianshan.md)

## Layers (planned)
- Extreme high altitude (>5000 m)
- Alpine
- Montane forests
- Lowland forests
- Ground / leaf litter / soil
- (Later) Ocean layers

Created for family exploration and wonder.
