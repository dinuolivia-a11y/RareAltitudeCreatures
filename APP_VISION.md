# Rare Altitude Creatures – Visione dell’App

## Idea principale
App educativa per bambini che permette di esplorare la Terra (e lo spazio) in discesa verticale.

### Flusso dell’esperienza
1. **Spazio**  
   Inizio con il sistema solare (immagini NASA realistiche).  
   Poi galassie e universo.  
   Possibilità di usare la chiave API NASA per dati e immagini reali.

2. **Terra**  
   Globo 3D ruotabile con il dito.  
   L’utente sceglie una zona (Himalaya, Amazzonia, Oceano, Deserto, ecc.).

3. **Discesa per altitudine**  
   Scrollando verso il basso ci si avvicina alla Terra.  
   A ogni fascia di altezza si vedono le creature che vivono a quell’altitudine.  
   In base alla zona scelta, si vedono solo le specie di quella zona.

4. **Dettaglio creatura**  
   Toccando una creatura si apre la scheda completa:  
   - Immagine  
   - Nome comune e scientifico  
   - Descrizione semplice  
   - Curiosità  
   - Altitudine / habitat

5. **Oceano**  
   Se si sceglie l’oceano, la discesa continua negli strati marini (sempre più in profondità).

6. **Curiosità del giorno**  
   Ogni giorno una curiosità sullo spazio e una sulla Terra (da fonti affidabili).

## Regole fondamentali del progetto
- Solo specie **precise e documentate** (niente generiche).
- Massimo **10 creature per zona**.
- Finire una zona prima di passare alla successiva.
- Niente fretta, niente scorciatoie.
- Immagini generate solo per specie specifiche, con tratti riconoscibili.
- Tutto indicizzato su GitHub.

## Struttura GitHub
- `zones/` → file markdown con le specie per ogni zona
- `images.md` → indice completo delle immagini generate
- `curiosities.md` → lista delle curiosità
- `APP_VISION.md` → questo documento

## Come riprendere il lavoro
Quando il contesto si perde, si può dire:

> “Amore, vai su GitHub, leggi APP_VISION.md e images.md e riprendiamo da dove eravamo rimasti.”
